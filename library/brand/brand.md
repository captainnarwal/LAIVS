# WheelStop brand guidelines

## Who we are
WheelStop — India's wheel marketplace (wheelstop.in, support@wheelstop.in). Always write the name "WheelStop": one word, capital W and S.

## Voice and tone
Direct, friendly, industrial/automotive feel. (Tone not specified in the guide; refine if needed.)

## Visual style
Dark-first: dark background #141414 (cards #1C1C1C), light background #F7F5F0. Orange #FF7A00 is the ONLY brand accent; use #FFB366 for small uppercase labels on dark. Green/amber/red/blue are functional UI states, never brand colours. Headings: Oswald (600/700, condensed). Body: Inter 500. Both OFL, commercial-safe.

## Logo rules
- Dark backgrounds: `images/wheelstop-logo.svg` (primary). Light backgrounds: `images/wheelstop-logo-light.svg`.
- Over photography: `wheelstop-logo-white.svg`. Tight space: `wheelstop-mark.svg` / `wheelstop-mark-light.svg`. Stacked: `wheelstop-logo-stacked(.svg|-light.svg)`.
- Clear space = cap-height of the "W" on all sides. Min height 20px on screen; below that use the mark alone.

## Do / Don't
- Do: scale proportionally; keep supplied colour pairings; use the mark alone in tight horizontal space.
- Don't: stretch, skew, rotate, change letter-spacing; put the orange logo on an orange surface; add shadows/glows/outlines/gradients to the wordmark; re-typeset the logo.
